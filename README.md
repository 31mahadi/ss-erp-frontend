# SS ERP Frontend

This is the frontend repository for SS ERP system.

## Repository Setup

This is a **separate repository** from the backend. 

- **Backend Repository**: `ss-erp-backend`
- **Frontend Repository**: This repository (to be created separately)

## Getting Started

When you're ready to initialize this as a separate git repository:

```bash
cd FE
git init
git remote add origin <your-frontend-repo-url>
git add .
git commit -m "Initial commit"
git push -u origin main
```

## Development

This folder is excluded from the backend repository via `.gitignore` in the parent directory.
